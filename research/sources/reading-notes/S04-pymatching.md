# S04 — PyMatching

Official README and Apache-2.0 license retrieved. Verified documentation: MWPM assumes independent graphlike mechanisms; Stim DEM construction and `decode_batch` return predicted observables. Correlated matching is a separate supported option and must be enabled explicitly. This study uses ordinary matching.

Important distinction: an exact matching solver is not an exact circuit-level likelihood model. Decomposition can expose correlations which standard matching does not model. Keep test-noise-informed matched prior separate from the fixed training prior. No README timing result is reused as an original project benchmark.
