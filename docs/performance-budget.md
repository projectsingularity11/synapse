# Performance budget

Targets, not measured guarantees: mobile LCP ≤2.5s, CLS ≤0.1, Lighthouse mobile performance ≥90 on reading path, accessibility ≥95; field INP ≤200ms when field data exist. Desktop scene target 60fps with named hardware. This SVG-first scene does not maintain an animation loop. Reduced effects are explicit and respect OS preferences. No images/fonts/audio on critical path. Client JS, route sizes, three Lighthouse runs and exact conditions belong in qa-report.md. No field data or universal zero-lag claims.
