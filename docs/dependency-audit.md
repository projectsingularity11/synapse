## Follow-up scientific visualization evaluation

No dependency was installed and no example code was copied in this pass. Exact retrieved files, hashes and HEAD commit-date evidence are in `research/sources/reading-notes/visualization-evidence.json`.

- **D3 official line/scale/axis docs**, `d3/d3` commit `db118c93a429e82b83f091dbaa18fd0a82c06130`, ISC license. Exact files: `docs/d3-shape/line.md`, `docs/d3-scale/linear.md`, `docs/d3-axis.md`, and `LICENSE`. HEAD patch date observed 2026-11-03. Useful principles: explicitly map data to scale domain/range, keep axes in the same coordinate system, and use straight segments for sparse measured settings. Its documented curve choices are not a reason to imply unsampled scientific values. No D3 code or package is adopted; the present four-point scientific plot can retain its small original SVG implementation.
- **Visx official responsive XYChart example**, `airbnb/visx` commit `485c0359664ee8e612992defb16e1f035ed40b23`, MIT license. Exact example: `packages/visx-demo/src/sandboxes/visx-xychart/Example.tsx`. Also inspected `packages/visx-demo/src/sandboxes/visx-threshold/Example.tsx` and `LICENSE`; HEAD patch date observed 2026-06-22. Examples expose width/height, margins, axes and explicit encodings. Those are useful review references for readable plot sizing, but the temperature mock data, curveBasis smoothing and area styling do not belong in these measured-result charts. No copy/adaptation or installation occurred. If adopted later, retain MIT copyright/license and record the exact copied lines and modifications first.
- **Observable Plot official repository**, `observablehq/plot` commit `2245188895e95ef2043f0ad12c2f900d6e48ef1a`, ISC license, README/LICENSE retrieved; HEAD patch date observed 2026-11-05. Candidate `test/plots/line.js` and `test/plots/dot.js` paths returned 404, so no exact example there is claimed to have been read. No package/example adoption follows from README-only review.

Recommendation: keep original artifact-bound SVG and native controls for now; improve the responsive viewBox/margins and labels, pointwise interval presentation, and adjacent readable tables. Use a deliberate narrow-screen composition or an explicitly labeled scrollable chart rather than shrinking 840px scientific labels until unreadable. All measured points, interval endpoints and bin counts must remain unchanged. The exact example licenses do not license linked mock-data assets or permit relabeling example data as project results.

## Synapse immersive redesign

Lenis is now adopted for desktop smooth scrolling. Official upstream README and MIT LICENSE were retrieved from https://raw.githubusercontent.com/darkroomengineering/lenis/main/ on this pass; the exact installed package/version is pinned in package-lock.json, and notices are generated from its installed license. Setup follows the official `new Lenis({ autoRaf: true })` pattern with tuned interpolation, anchors and cleanup. No reference-site source was retrieved or copied: requests to lusion.co and unseen.co returned CONNECT 403. The particle shader and route curtain are original. Self-hosted Manrope variable font comes from google/fonts/ofl/manrope/Manrope[wght].ttf under OFL; full license retained in public/fonts/OFL-Manrope.txt. Prior system-font-only and Lenis-not-adopted notes describe the earlier version, not this redesign.

The full Manrope variable font is distributed as WOFF2 after fontTools/Brotli container recompression, from 164700 to 53680 bytes (see actual file size and public/fonts/provenance.json). No glyph subsetting or outline changes. The uncompressed download is not shipped.
