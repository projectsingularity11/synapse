# Architecture

Next.js App Router / TypeScript. Editorial routes are server-rendered. A small client island handles navigation preferences and another handles replay controls. Offline Python training writes small JSON artifacts, read by server components and validated before publication. Scientific coordinates come from Stim detector coordinates; inputs are flattened detector bits. No guessed lattice-to-time tensor.

All scientific reading and primary replay use semantic HTML and SVG. An explicitly activated dynamic React Three Fiber/Drei island lifts the exact detector history into spatial time layers. It uses instanced geometry, capped DPR and on-demand rendering; the canvas unmounts offscreen. SVG, captions and tables remain complete when WebGL is unavailable. Native scrolling replaces a scroll controller. No database, background API, runtime training or browser agent orchestration. npm package versions and lockfile are pinned.
