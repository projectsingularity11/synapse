# Accessibility

Target WCAG 2.2 AA. Semantic headings, visible focus, skip navigation, native disclosure/menu and form controls, minimum 44px controls, reduced effects, no audio autoplay, no drag requirement. All content is available without WebGL. Charts have captions and adjacent numeric tables; shapes and text reinforce color. Replay has detection-event text and observable labels. Automated axe and keyboard checks are useful evidence but not a full conformance audit. Manual screen-reader verification remains a disclosed limitation.
